# DAS 사용 가이드

DAS(Data Analysis System)는 시험 네트워크 캡처를 장치·연결·IDL 구성에 맞춰 해석하고, 분석 결과를 시각화·문서화하는 Windows 데스크톱 프로그램입니다.

![DAS 시간선 분석 화면 -- 장치 사이 메시지 흐름과 선택한 메시지의 해석된 필드](assets/hero.png)

**[⬇ 최신 배포판 받기](https://github.com/WildCork/DAS_PUBLIC/releases/latest)** · [설치와 실행](guide/install.md) · [사용 가이드](#사용-가이드)

이 저장소에는 DAS **사용 가이드**와 실행 파일 **배포판**(Releases)이 있습니다. 소스 코드는 들어 있지 않습니다. 가이드는 프로그램 안의 `F1` 도움말(탭마다 그 탭의 설명)과 같은 원본에서 만들며, 설정 파일 작성 규칙·문제 해결 같은 공통 항목과 화면별 스크린샷·번호 설명이 함께 들어 있습니다.

> DAS는 저장된 PCAPNG와 legacy PCAP 파일을 분석하는 프로그램입니다. 패킷을 직접 캡처하지는 않으며, dumpcap 등이 기록 중인 파일을 따라가며 읽는 실시간 로드를 지원합니다.

## 무엇을 할 수 있나요?

| 단계 | 기능 | 주요 결과 |
|---|---|---|
| ① 장치 / IDL | 장치, IP/포트 소켓, IDL과 보조 규칙 등록 | 시험 구성 |
| ② 연결 설정 | 발신·수신 소켓과 IDL 연결 | 방향별 메시지 해석 규칙 |
| ③ 시험 분석 설정 | 캡처 로드, 메시지·스마트 필터, 요청-응답 관계 설정 | 분석 대상 데이터 |
| ④ 시각화 | 시간선, 주기성, 연속성, 응답성 분석 | 차트, 통계, CSV/XLSX, 이미지 |
| ⑤ 시험분석결과 | 성적서와 다중 Y축 대시보드 작성 | CSV/XLSX 성적서, PDF 대시보드 |

이 밖에 설정·양식·작업 세션 저장, 진단 패키지, 한국어/영어 전환, 밝은/어두운 테마와 글자 크기 조절을 지원합니다.

## 빠른 시작

```text
① 장치 / IDL → ② 연결 설정 → ③ 시험 분석 설정
→ ④ 시각화 → ⑤ 시험분석결과
```

1. 기존 DAS 설정 JSON 또는 `endpoints.lua`를 불러오거나, 장치·IDL·연결을 직접 등록합니다.
2. ③ 시험 분석 설정에서 `.pcapng` 또는 `.pcap` 파일을 불러옵니다.
3. 메시지 트리에서 분석할 종류를 선택하고 **필터 적용**을 누릅니다.
4. ④ 시각화의 네 분석 탭에서 흐름·주기·필드값·응답시간을 확인합니다.
5. ⑤ 시험분석결과에서 성적서 또는 대시보드를 구성하고 저장합니다.

화면이 비어 있거나 메시지가 해석되지 않으면, 앞 단계의 장치 IP/포트, 연결 방향, IDL이 실제 캡처와 일치하는지 먼저 확인합니다.

## 지원 파일

### 입력

| 형식 | 용도 |
|---|---|
| `.pcapng`, `.pcap` | 시험 네트워크 캡처 |
| `.idl` | 메시지 구조와 필드 정의 |
| `.das-idl.json` | IDL 메타데이터와 보조 분석 규칙 |
| `.lua` | 장치·소켓·연결 구성 |
| `.json` | DAS 설정, 성적서 양식, 대시보드 양식 |

### 출력

| 형식 | 용도 |
|---|---|
| `.csv`, `.xlsx` | 파싱 데이터와 성적서 |
| `.png`, `.jpg` | 시각화 화면 |
| `.pdf` | 대시보드 결과 |
| `.txt`, `.zip` | 진단 내용과 지원 패키지 |

JSON 파일은 확장자가 같아도 파일 안의 `format`과 `version`으로 용도를 구분합니다.

## 실행 옵션

설정과 캡처를 지정해 실행할 수 있습니다.

```powershell
DAS.exe --config "C:\시험\endpoints.lua" --pcapng "C:\시험\capture.pcapng"
```

| 옵션 | 설명 |
|---|---|
| `--config <path>` | DAS 설정 JSON 또는 Lua 구성 불러오기 |
| `--pcapng <path>` | 캡처를 불러온 뒤 시각화 단계로 이동 |

## 시스템 요구사항

- Windows 10/11 64-bit
- 1280×720 이상 화면 권장
- 필요한 메모리는 캡처 크기와 분석 종류에 따라 달라집니다.
