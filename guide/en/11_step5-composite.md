# ⑤ Analysis Results · Dashboard

Lays out continuity field values as multi-Y-axis graphs in several XY areas to compare them on one screen. All areas share one X-axis (elapsed time).

**How to use**

1. Create an area with "Add XY Area", then pick message → field → name/color with "Add Graph" in its settings panel (up to 5 per area).
2. The Y-axis is auto-ranged by default; entering a min/max fixes it there.
3. Ctrl+wheel zooms and dragging or Shift+wheel pans, moving all areas together; "Fit X-Axis to Full Range" resets.
4. Click "X-Axis Settings" or an X-axis tick row to set the range and grid spacing yourself.
5. Drag an area's handle or a message button to reorder (Alt+↑/↓ works too).
6. Reuse the layout with "Save Template"/load, and create a PDF with the shared "Save Results".

**Notes**

- A template holds only the layout, not data, zoom state or ranges.
- Graphs whose message/field cannot be found stay and are shown as "No target".
- Ranges created in ④ Visualize appear in the background and are read-only here.
- The PDF uses the on-screen X range at save time and puts one area per page.
