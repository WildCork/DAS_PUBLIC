# About

DAS (Data Analysis System) is a Windows desktop program that interprets launch test network captures according to device/IDL specs and organizes them into visualizations and reports.

**Notes**

- Supports a Korean/English UI, dark/light themes, and 75~175% font-size scaling.
- Built with Qt6/C++.
