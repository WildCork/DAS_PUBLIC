# Shortcuts and Supported File Types

Frequently used shortcuts, and the file types DAS actually reads and writes.

**Notes**

- F1: Open help / jump to the current screen's topic
- Ctrl+S: Save Config  ·  Ctrl+L: Load Config  ·  Ctrl+O: Open PCAPNG File
- F11: Toggle fullscreen
- Ctrl+=, Ctrl+-, Ctrl+0: Zoom in / zoom out / reset font size
- Input files: PCAPNG capture (.pcapng), IDL (.idl), Lua endpoint map (.lua), DAS config (.json), report format (.json)
- Output files: graph images (.png, .jpg), parsed data (.csv, .xlsx), report (.xlsx, .csv)
