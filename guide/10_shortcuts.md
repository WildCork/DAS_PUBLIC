# 단축키 및 지원 파일 형식

자주 쓰는 단축키와, DAS가 실제로 읽고 쓰는 파일 형식입니다.

**주의사항**

- F1: 도움말 열기/현재 화면 항목으로 이동
- Ctrl+S: 설정 저장  ·  Ctrl+L: 설정 불러오기  ·  Ctrl+O: PCAPNG 파일 열기
- F11: 전체 화면 전환
- Ctrl+=, Ctrl+-, Ctrl+0: 글자 크기 확대 / 축소 / 기본 크기
- 입력 파일: PCAPNG 캡처(.pcapng), IDL(.idl), Lua 엔드포인트 맵(.lua), DAS 설정(.json), 성적서 양식(.json)
- 출력 파일: 그래프 이미지(.png, .jpg), 파싱 데이터(.csv, .xlsx), 성적서(.xlsx, .csv)
