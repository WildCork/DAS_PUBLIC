# ④ 시각화 · 응답성

③ 탭에서 정의한 요청-응답 관계마다 요청에서 응답까지 걸린 시간을 시계열로 보여 줍니다. 응답 누락·중복·고아도 함께 표시합니다.

**사용 순서**

1. 관계는 ③ 시험 분석 설정의 "관계 추가"에서 만들고, 이 탭에서는 목록 체크로 표시 여부만 고릅니다.
2. 그래프의 X축은 요청 시각, Y축은 응답시간(ms)입니다.
3. 점이나 이상 마커를 클릭하면 오른쪽 아래 "선택 이벤트 상세"에 요청·응답 프레임과 판정 근거가 나옵니다.
4. 상세의 "시간선에서 보기"로 그 프레임으로 바로 이동합니다.
5. "선택된 데이터 내보내기"로 표시한 관계의 이벤트를 CSV/Excel로 저장합니다.

**주의사항**

- 다음 요청까지 응답이 없으면 누락(붉은 X), 두 번 이상이면 중복(주황 원), 어느 요청에도 속하지 않으면 고아(보라 역삼각형)입니다.
- 누락·중복·고아는 값을 0으로 그리지 않으며, 누락 앞뒤의 점도 선으로 잇지 않습니다.
- 시간 북마크와 구간은 네 시각화 탭이 함께 쓰며, 그래프를 우클릭해 추가·수정·삭제합니다.
- 가리키는 메시지를 찾지 못한 관계는 "사용 불가"로 표시되고 분석되지 않습니다.
