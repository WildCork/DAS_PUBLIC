# ⑤ 시험분석결과 · 대시보드

연속성 필드 값을 여러 XY 영역에 다중 Y축 그래프로 배치해 한 화면에서 비교하는 탭입니다. 모든 영역이 X축(경과 시간)을 함께 씁니다.

**사용 순서**

1. "XY 영역 추가"로 영역을 만들고, 설정 패널의 "그래프 추가"로 메시지 → 필드 → 이름/색상을 고릅니다(영역당 최대 5개).
2. Y축은 기본이 자동 범위이며, 최솟값/최댓값을 넣으면 그 값으로 고정됩니다.
3. Ctrl+휠로 확대하고 끌기나 Shift+휠로 이동하면 모든 영역이 같은 시간 범위로 움직이며, "X축 전체 보기"로 되돌립니다.
4. "X축 설정"이나 X축 눈금 줄을 눌러 범위와 격자 간격을 직접 정합니다.
5. 영역 손잡이나 메시지 버튼을 끌어 순서를 바꿉니다(Alt+↑/↓도 가능).
6. "양식 저장"/"불러오기"로 구성을 다시 쓰고, 공통 "결과 저장"으로 PDF를 만듭니다.

**주의사항**

- 양식에는 구성만 들어가며 데이터·확대 상태·구간 영역은 들어가지 않습니다.
- 찾지 못한 메시지/필드의 그래프는 지워지지 않고 "대상 없음"으로 표시됩니다.
- ④ 시각화에서 만든 구간 영역이 배경에 함께 보이며, 여기서는 조회만 됩니다.
- PDF는 저장할 때 화면의 X축 범위를 쓰고, 영역 하나당 한 쪽씩 만듭니다.
