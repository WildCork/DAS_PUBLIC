# 설치와 실행

DAS는 설치 과정이 없습니다. 압축을 풀고 `DAS.exe`를 실행하면 됩니다.

## 1. 받기

이 저장소의 **Releases** 페이지에서 가장 최근의 `DAS_Release_<날짜>.zip`을 받습니다.

## 2. 압축 풀기

원하는 폴더(예: `C:\DAS`)에 압축을 풉니다. 다음과 같은 폴더가 생깁니다.

| 폴더 | 내용 |
|---|---|
| `Run\` | `DAS.exe`와 실행에 필요한 Qt 라이브러리(DLL) |
| `Data\` | 예시 설정(`endpoints.json`), IDL 파일, 예시 캡처(`launch_result_*.pcapng`), 성적서 양식 예시 |
| `README.md` | 프로그램 소개 |

- `Run\` 폴더 안의 파일은 함께 있어야 합니다. `DAS.exe`만 다른 곳으로 복사하면 실행되지 않습니다.
- 바탕화면 바로가기가 필요하면 `DAS.exe`를 복사하지 말고 **바로 가기 만들기**를 쓰세요.

## 3. 실행

`Run\DAS.exe`를 더블클릭합니다.

- Windows가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누릅니다.
- 처음 실행하면 빈 ① 장치 / IDL 탭이 열립니다. 언어(한국어/English)와 테마는 실행 중에 바꿀 수 있습니다.
- 어느 탭에서든 `F1`을 누르면 그 탭의 도움말이 열립니다.

## 4. 예시 데이터로 처음 열기

1. ① 장치 / IDL 탭에서 초록색 **시험분석설정 불러오기**를 누르고 `Data\endpoints.json`을 고릅니다. 장치·IDL·연결이 한 번에 채워집니다.
2. ③ 시험 분석 설정 탭으로 가서 **찾아보기...**로 `Data\launch_result_1k.pcapng`를 고르고 **로드**를 누릅니다.
3. 오른쪽 메시지 트리에서 볼 메시지를 체크하고 초록색 **필터 적용**을 누릅니다.
4. ④ 시각화 탭의 시간선·주기성·연속성·응답성에서 결과를 확인합니다.
5. ⑤ 시험분석결과 탭에서 성적서나 대시보드를 만들어 저장합니다.

명령줄에서 설정과 캡처를 한 번에 열 수도 있습니다(`Run\` 폴더에서 실행).

```powershell
.\DAS.exe --config ..\Data\endpoints.json --pcapng ..\Data\launch_result_1k.pcapng
```

`launch_result_10k.pcapng`는 같은 시나리오의 더 긴 캡처이고, `_withNoise`·`_anomaly`는 잡음과 이상 상황이 섞인 캡처입니다.

## 5. 저장 위치와 제거

- 프로그램 설정과 작업 세션은 `%LOCALAPPDATA%\DAS` 아래에 저장됩니다. 압축을 푼 폴더에는 쓰지 않습니다.
- 제거하려면 압축을 푼 폴더를 지우고, 설정까지 지우려면 `%LOCALAPPDATA%\DAS`도 지웁니다.

## 시스템 요구사항

- Windows 10/11 64-bit
- 1280×720 이상 화면 권장
- 필요한 메모리는 캡처 크기에 따라 달라집니다(대략 패킷 100만 개당 0.1 GB + 0.5 GB).
